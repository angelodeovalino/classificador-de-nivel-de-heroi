# classificador-de-nivel-de-heroi
Desafio de projeto #1 do curso de Lógica de Programação da DIO.

###### Descrição:

Utilizei todas as obrigatoriedades pedidas no projeto:

* Variáveis
* Operadores (em específico os de comparação e lógicos).
* Laços de repetição: utilizei o laço for para criar um sistema de ganho de xp com base no nível que quero que o personagem adquira.
* Estruturas de decisões: utilizei o switch case para definir com base no xp, qual é o nível do herói.
